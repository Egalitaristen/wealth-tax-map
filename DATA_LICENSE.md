## What the licence does not cover

- **Quotes** in the `quote_original` column are short extracts from the cited sources. They remain under the copyright of their publishers and are included for attribution and verification.
- **Boundary files** (`boundaries.json`) keep the licence of their source, named inside each file. The UK file uses ONS data under the Open Government Licence v3.0 (contains OS data © Crown copyright and database right). The Swedish file uses Statistics Sweden's (SCB) digital boundaries, released under CC0. The US file uses US Census Bureau cartographic boundaries (public domain) via the us-atlas package. The German file uses © BKG (2026), VG250 (Gemeinden, Kreise and Länder as of 1 January 2026), under the Datenlizenz Deutschland – Namensnennung – Version 2.0 (data sources: https://sgx.geodatenzentrum.de/web_public/gdz/datenquellen/datenquellen_vg_nuts.pdf). The Indian file uses the Survey of India's district and state boundaries (Online Maps Portal), as republished under CC0 1.0 by the DataMeet community (ramSeraph/indian_admin_boundaries), which asks that Survey of India and DataMeet be credited; India's Geospatial Guidelines (2021) make SoI boundary data free to download, display and print. The French file uses Etalab's contours administratifs 2025 (communes, départements and regions, generalised to 1000 m), derived from IGN Admin Express, under the Licence Ouverte 2.0. The Spanish file uses the Instituto Geográfico Nacional's (IGN) municipality, province and autonomous-community boundaries under CC BY 4.0 (© Instituto Geográfico Nacional), via the es-atlas package; the Canary Islands are moved into an inset. The Brazilian file uses IBGE's 2020 município and state boundaries as republished by OCHA ROLAC in the Common Operational Dataset on HDX (cod-ab-bra), under the Creative Commons Attribution for Intergovernmental Organisations licence (CC BY-IGO). The site prints each file's source on the country's Method page.
- **World outlines** in `site/vendor/` come from the `world-atlas` package (Natural Earth, public domain).
